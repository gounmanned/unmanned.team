Slack

This guide walks you through connecting Slack so VEX can post events to a channel of your choice.

Step 1: Install the Slack app

  1. Go to https://unmanned.team/slack and click to connect.
  2. When Slack asks which channel VEX should post to, choose it (e.g. #alerts).
  3. Review the permissions and click "Allow".

Step 2: Attach to your VEX account

  1. Find your Slack team ID: open Slack in a web browser and check the address bar. It reads something like app.slack.com/client/T0123ABCD/… — the part starting with T is your team ID.
  2. In VEX, add the Slack monitor using this JSON:
{
    "teamID": ""
}
  1. Connect.
