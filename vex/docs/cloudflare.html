Cloudflare

This guide walks you through creating a Cloudflare API token so Vex can monitor security events across your zones. There are two approaches below: a full access token that's quick to set up, and a restricted token that's scoped to only what Vex needs. Pick whichever fits your risk tolerance.

Prerequisites

  • You have access to your Cloudflare account with domains configured.
  • Your account has Admin or Super Administrator privileges.

Step 1: Access API Token Management

  1. Log into your Cloudflare Dashboard.
  2. Navigate to the Manage Account -> Account API tokens section
  3. Under "Create token", click "Get started".
  4. Set the Token name to Vex.

Step 2, Option A: Full Access Token

Note: This token can read and write every resource in the account. It's the fastest way to get Vex connected, but treat it like a master key — store it accordingly. Use Option B below if you'd rather scope it down.
  1. Select the "Read all resources" template — this populates one permission policy row per resource group, each set to Read
  2. Go through every row it added and check Edit as well, wherever that option is available (some groups, like Analytics or Logs, are read-only and won't have an Edit option — leave those as-is)
  3. Ensure "Entire Account" is selected (it is by default)
  4. Select an expiration (or "No Expiration")
  5. Click "Review token"
  6. Click "Create token"

Step 2, Option B: Restricted Token

Note: This token is scoped to only the permissions Vex actually uses: account-wide read visibility, domain and analytics read access, and read/write access to DNS, zone settings, and WAF rules.
  1. Check "Read all resources" under permission policies
  2. Click to add another policy
  3. Search for "Registrar Domains" and check Read
  4. Click to add another policy
  5. Select "Analytics & Logs" then "Zone Analytics" and check Read
  6. Click to add another policy
  7. Select "DNS" and check both Read and Edit
  8. Click to add another policy
  9. Select "Zone" and check both Read and Edit
  10. Click to add another policy
  11. Select "App Security" then "Zone WAF Rules" and check both Read and Edit
  12. Ensure "Entire Account" is selected (it is by default), or scope to specific zones for even tighter access
  13. Select an expiration (or "No Expiration")
  14. Click "Review token"
  15. Click "Create token"

Step 3: Connect Vex

Add the following JSON to Vex, using the token from whichever option you chose above:

{
    "account_id": "your_cloudflare_account_id",
    "api_token": "your-api-token-here"
}
