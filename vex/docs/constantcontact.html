Constant Contact

This guide walks you through registering an application with Constant Contact and completing the OAuth2 authorization flow. The resulting credentials will allow us to monitor security events and detect suspicious activity in your Constant Contact account.

Prerequisites

  • You have admin access to your Constant Contact account
  • You can access the Constant Contact Developer Portal

Step 1: Create an Application

  1. Log in to the Constant Contact V3 API Developer Portal (sign up for a developer account first if you don't already have one).
  2. From the My Applications tab, click New Application.
  3. Fill in the app details:
  • App name: Vex
  • OAuth2 flows: Authorization Code Flow
  • Refresh token type: Long Lived (recommended)
  1. Click Create.

Step 2: Get Your API Key and Client Secret

  1. Click Edit next to your new application.
  2. Copy the API Key shown in the Details view — this is your client_id.
  3. Click Generate Client Secret and copy it immediately. The secret is only shown once.
  4. Keep the default Redirect URI for your application (https://localhost ).
  5. Click Save.

Step 3: Authorize the Application

  1. Build an authorization request URL using your client_id and redirect_uri:
https://authz.constantcontact.com/oauth2/default/v1/authorize?
client_id={client_id}&redirect_uri={redirect_uri}&response_type=code&
scope=account_read contact_data campaign_data offline_access&state={random_string}
  1. Open the URL in a browser, log in, and grant Vex access to your account.
  2. You'll be redirected to your redirect URI with a code query parameter. Copy it — authorization codes expire after 5 minutes and can only be used once.

Step 4: Exchange the Code for a Refresh Token

  1. Base64-encode your client_id and client_secret together, separated by a colon:
echo -n "{client_id}:{client_secret}" | base64
  1. Make a POST request to the token endpoint, using the output from step 1 as the Authorization header value (the placeholder below stands in for that base64 string — do not paste it literally):
curl -X POST "https://authz.constantcontact.com/oauth2/default/v1/token" \
        -H "Authorization: Basic {base64_encoded_client_id_and_secret}" \
        -H "Content-Type: application/x-www-form-urlencoded" \
        -d "grant_type=authorization_code" \
        -d "code={code}" \
        -d "redirect_uri=https://localhost"
  1. The response includes an access_token and a refresh_token.

Step 5: Save to Vex

Inside Vex, add the credentials in the following JSON format:

{
  "client_id": "your client id",
  "client_secret": "your client secret",
  "refresh_token": "your_refresh_token"
}
