Slack

This guide walks you through creating a Slack incoming webhook so Vex can send events to a channel of your choice.

Notification integration: Slack is a notification integration, not a security monitor. It doesn't scan or find issues on its own — it delivers events (alerts, status changes, connection updates, etc.) from your other security monitors into Slack in real time. Set up a security monitor separately to generate the events this integration will notify you about.

Prerequisites

  • You have access to your Slack workspace with permission to add apps.
  • You've identified the channel you want notifications sent to.

Step 1: Create a Slack App

  1. Go to api.slack.com/apps and log into your workspace.
  2. Click "Create New App".
  3. Choose "From scratch".
  4. Set the App Name to Vex Notifications and select your workspace.
  5. Click "Create App".

Step 2: Enable Incoming Webhooks

  1. From your app's settings page, select "Incoming Webhooks" under Features.
  2. Toggle "Activate Incoming Webhooks" to on.
  3. Click "Add New Webhook to Workspace" at the bottom of the page.

Step 3: Choose a Channel

  1. Select the channel you want Vex to post notifications to.
  2. Click "Allow".

Step 4: Copy the Webhook URL

  1. Back on the "Incoming Webhooks" page, find the webhook listed under "Webhook URLs for Your Workspace".
  2. Click "Copy" to copy the URL. It will look like:
Treat this URL as a secret. Anyone who has it can post messages to your channel. Don't commit it to source control or share it outside your team.

Step 5: Upload Webhook to Vex

  1. Create a new text file and name it slack.json.
  2. Using the URL from Step 4, create a JSON object with this structure:
{
    "webhook": "https://hooks.slack.com/services/your-webhook-path-here"
}
  1. Save this in Vex
