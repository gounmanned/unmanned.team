GoDaddy

This guide walks you through creating a GoDaddy API key so VEX can monitor the domains registered in your GoDaddy account. VEX watches for domains that can be transferred away or are about to expire, and for domains that use GoDaddy DNS it checks (and fixes) your email security records — SPF, DMARC, and MX.

Prerequisites

  • You can sign in to the GoDaddy account that owns your domains.
  • Your account is eligible for GoDaddy's production API (see the note below).
Note: GoDaddy only allows production API access for accounts with 10 or more domains or a Discount Domain Club plan. Smaller accounts can still create a key, but VEX will report "access denied (403)" when connecting. If that happens, contact GoDaddy about API access, or move your DNS to Cloudflare so VEX can monitor it there.

Step 1: Open the Developer Portal

  1. Go to the GoDaddy Developer Portal — API Keys.
  2. Sign in with the GoDaddy account that owns your domains.

Step 2: Create an API Key

  1. Click "Create New API Key".
  2. Set the Name to VEX.
  3. Set the Environment to Production (not OTE — OTE is GoDaddy's test environment and can't see your real domains).
  4. Click "Next".
  5. Copy the Key and the Secret.
Note: GoDaddy only shows the secret once. GoDaddy keys can't be scoped, so this key can manage every domain in the account — treat it like a password and store it accordingly.

Step 3: Save

Add the following JSON to VEX, using the key and secret from Step 2:

{
    "api_key": "your-api-key-here",
    "api_secret": "your-api-secret-here"
}
