Square

Uses your Square personal access token (full access to your account), to watch for new team members, disputes, card changes and bank account activity.

  1. Square Developer Console → Applications → open your application, or Create your first application → name it Security monitor → Save.
  2. Credentials → set the environment to Production → Personal Access Token → Show → copy it.
  3. Fill in: 
    {
  "token": ""
}
    FieldWhere to find it
    tokenThe token from step 2
