Microsoft 365

This guide walks you through creating an Azure application registration with the necessary permissions to access Microsoft Defender for Business alerts. The resulting credentials (Tenant ID, Client ID, and Client Secret) will allow API access to:

  • Microsoft Defender for Business alerts
  • Microsoft Graph Security API

Prerequisites

  • You have a Global Administrator or Application Administrator role in your Microsoft 365 tenant.

Step 1: Register an Application

  1. Go to Azure Portal → App registrations.
  2. Click "New registration".
  3. Set the name to Vex.
  4. Under "Supported account types", select "Single tenant only".
  5. Leave "Redirect URI" blank.
  6. Click "Register".

Step 2: Note Your Application Details

  1. On the app's Overview page, copy and save:
  2. Application (client) ID - You'll need this as your Client ID.
  3. Directory (tenant) ID - You'll need this as your Tenant ID.

Step 3: Create a Client Secret

  1. Go to "Certificates & secrets" in the left menu.
  2. Under "Client secrets", click "New client secret".
  3. Add a description like Security Monitor.
  4. Set expiration (recommended: 24 months).
  5. Click "Add".
  6. Important: Copy the Value immediately - this is your Client Secret and won't be shown again.

Step 4: Configure API Permissions

  1. Go to "API permissions" in the left menu.
  2. Click "Add a permission".
  3. Select "Microsoft Graph".
  4. Choose "Application permissions" (not Delegated).
  5. Search for and add these permissions:
User.Read.All
Group.Read.All
Device.Read.All
ServiceMessage.Read.All
AuditLog.Read.All
Organization.Read.All
SecurityAlert.ReadWrite.All
Sites.Read.All
Files.Read.All
Policy.Read.All
User.EnableDisableAccount.All
User.RevokeSessions.All
  1. Click "Add permissions".
  2. Important: Click "Grant admin consent for [Your Organization]".
  3. Confirm by clicking "Yes".

Step 5: Connect Vex

  1. Using the values from the previous steps, create a JSON object with this structure:
{
    "tenant_id": "your-directory-tenant-id-here",
    "client_id": "your-application-client-id-here", 
    "client_secret": "your-client-secret-value-here"
}
  1. Replace the placeholder values with your actual credentials:
  2. tenant_id: The Directory (tenant) ID from Step 2
  3. client_id: The Application (client) ID from Step 2
  4. client_secret: The secret value from Step 3
  5. Paste this JSON in the credentials input inside Vex.
  6. Click Connect.
