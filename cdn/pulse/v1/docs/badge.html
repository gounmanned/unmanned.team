Badge

A small label for status, severity or metadata. Not clickable; for a tag people can toggle, use a chip.

Options

ClassWhat it does
pulse-badge--accent, --success, --warning, --danger, --infoTone. No tone class is neutral gray. Accent is for brand moments only (“New”).
pulse-badge--solidFilled with the tone.
pulse-badge--outlineA border in the tone, no fill.
pulse-badge--nodotHides the dot.
pulse-badge--monoMono caps, no dot, gray unless a tone follows.

Accessibility

  • Always pair a tone with a word. “Failed” in red, never a red dot alone.

Badge: every state
