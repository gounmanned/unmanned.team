Rapid7 InsightIDR

This guide walks you through creating an InsightIDR webhook so new signals get pushed into your SOC platform as raw logs.

Step 1: Open Event Sources

  1. In InsightIDR, go to Data Collection.
  2. Select the "Event Sources" tab.
  3. Click "Add Event Source".

Step 2: Add a Custom Logs Webhook

  1. Under "Add Raw Data", select "Custom Logs".
  2. Set the collection method to "Webhook".
  3. Give it a name, for example "Vex Signals", then click "Save".

Step 3: Copy the Webhook URL

  1. Once the event source is created, copy the webhook URL InsightIDR generates for it.
  2. It will look like:
https://xxxxx.data.logs.insight.rapid7.com/log/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

Step 4: Save to Vex

  1. In the configuration input box, create a JSON object with this structure:
{
    "webhook": "https://xxxxx.data.logs.insight.rapid7.com/log/your-log-token-here"
}
