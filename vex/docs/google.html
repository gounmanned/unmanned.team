Google Workspace

This guide covers connecting a client's Google Workspace to Vex.

Step 1: Add permissions

  1. Visit Admin Console → Security → API Controls.
  2. Click "Manage Domain-Wide Delegation".
  3. Click "Add new".
  4. Paste the Vex Client ID of 109138343248974999069.
  5. Add the following scopes:
    https://www.googleapis.com/auth/apps.alerts
    https://www.googleapis.com/auth/drive.readonly
    https://www.googleapis.com/auth/admin.directory.device.chromeos.readonly
    https://www.googleapis.com/auth/admin.directory.user
    https://www.googleapis.com/auth/admin.directory.user.security
  1. Click Save.

Step 2: Save to Vex

  1. Select Google from the list of available integrations.
  2. Enter {} in the configuration box.
  3. Click Connect.
