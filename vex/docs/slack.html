Slack

This guide walks you through connecting Slack so VEX can send events to a channel of your choice, using a Slack bot.

Notification integration: Slack is a notification integration, not a security monitor. It doesn't scan or find issues on its own — it delivers events (alerts, status changes, connection updates, etc.) from your other security monitors into Slack in real time. Set up a security monitor separately to generate the events this integration will notify you about.

Step 1: Create a Slack App

  1. Go to api.slack.com/apps and log into your workspace.
  2. Click "Create New App".
  3. Choose "From scratch".
  4. Set the App Name to VEX Notifications and select your workspace.
  5. Click "Create App".

Step 2: Add the Bot Token Scopes

  1. From your app's settings page, select "OAuth & Permissions" under Features.
  2. Scroll to "Scopes" and, under "Bot Token Scopes", click "Add an OAuth Scope".
  3. Add the following scopes:
    • chat:write
    • app_mentions:read
    • commands
    • channels:history
    • users:read
    • users:read.email

Step 3: Install the App

  1. Scroll back to the top of the "OAuth & Permissions" page.
  2. Click "Install to Workspace", review the permissions, and click "Allow".

Step 4: Copy the Bot Token

  1. After installing, you'll land back on "OAuth & Permissions".
  2. Copy the "Bot User OAuth Token" at the top of the page. It starts with xoxb-.
Treat this token as a secret. Anyone who has it can post messages as your bot. Don't commit it to source control or share it outside your team.

Step 5: Choose a Channel

  1. Decide which channel you want VEX to post notifications to, and note its name (e.g. #security-alerts).
  2. In Slack, open that channel and invite the bot with: 
    /invite @VEX Notifications
The bot must be a member of the channel. If it isn't invited, VEX won't be able to post there and connection testing will fail with not_in_channel.

Step 6: Upload Bot Credentials to VEX

  1. Create a new text file and name it slack.json.
  2. Using the token from Step 4 and the channel from Step 5, create a JSON object with this structure:
{
    "token": "xoxb-your-bot-token-here",
    "channel": "#security-alerts"
}
  1. Save this in VEX
