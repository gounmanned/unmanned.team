Amazon Web Services

This guide walks you through deploying a read-only IAM role in your AWS account using CloudFormation. This role allows Vex to securely connect to your AWS environment to monitor security findings, inventory resources, and perform other read-only operations.

  • AWS Security Hub findings
  • GuardDuty alerts
  • EC2 instance and volume inventory
  • IAM user and role auditing
  • CloudTrail event lookup
  • S3 bucket configuration (not object contents)
Vex is granted read-only access only. It cannot modify, delete, or create any resources in your account. Secret values and encryption keys are explicitly denied.

Prerequisites

  • You have access to the AWS Management Console
  • Your IAM user or role has permission to create IAM roles and deploy CloudFormation stacks

Step 1: Download the CloudFormation Template

Copy the template below. You will upload it to CloudFormation in the next step.

AWSTemplateFormatVersion: '2010-09-09'
Description: Read-Only Cross-Account Access Role

Parameters:
  VexAccountId:
    Type: String
    Default: 418606469629
    Description: Vex AWS Account ID

Resources:
  Vex:
    Type: AWS::IAM::Role
    Properties:
      RoleName: Vex
      AssumeRolePolicyDocument:
        Version: '2012-10-17'
        Statement:
          - Effect: Allow
            Principal:
              AWS: !Sub 'arn:aws:iam::${VexAccountId}:root'
            Action: sts:AssumeRole
            Condition:
              StringEquals:
                sts:ExternalId: !Sub '${AWS::AccountId}'
      ManagedPolicyArns:
        - arn:aws:iam::aws:policy/SecurityAudit
        - arn:aws:iam::aws:policy/AmazonS3ReadOnlyAccess

Outputs:
  RoleArn:
    Value: !GetAtt Vex.Arn
    Description: Paste this Role ARN into Vex

Step 2: Open CloudFormation

  1. Log into the AWS CloudFormation Console.
  2. Make sure you are in the correct AWS region (top-right corner). Any region works — IAM roles are global.
  3. Click "Create stack" and select "With new resources (standard)".

Step 3: Upload the Template

  1. Under Specify template, select "Upload a template file".
  2. Save the template you copied in Step 1 as a file named vex-role.yml on your computer.
  3. Click "Choose file" and select vex-role.yml.
  4. Click "Next".

Step 4: Configure the Stack

  1. Set the Stack name to monitor.
  2. Leave the VexAccountId parameter as-is — it is pre-filled with Pink Duck's account ID.
  3. Click "Next".
  4. Click "Next" again on the Configure stack options page (no changes needed).
  5. On the Review page, scroll to the bottom and check the box acknowledging that CloudFormation may create IAM resources.
  6. Click "Submit".

Step 5: Retrieve the Outputs

  1. Wait for the stack status to show CREATE_COMPLETE (usually under one minute).
  2. Click the stack name Vex to open it.
  3. Click the "Outputs" tab.
  4. You will see:
    • RoleArn — e.g. arn:aws:iam::123456789012:role/Vex

Step 6: Connect to Vex

  1. Log into your Vex dashboard.
  2. Go to Monitors > AWS.
  3. Paste both values in the following format and click Save:
{"account":"<YOUR-AWS-ACCOUNT-ID>", "role":"<RoleArn>", "region":"<YOUR-AWS-REGION>"}
