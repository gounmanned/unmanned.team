Data table

A table for comparing rows: sortable columns, a selected row, and the same row heights as lists.

Sorting

A sortable head cell holds a <button class="pulse-table__sort"> with an arrow-down icon, and the cell carries aria-sort="ascending" or "descending" (the icon turns for ascending and shows on hover otherwise). Sorting the rows is the page’s script.

Options

OptionWhat it does
pulse-table--compact, --spaciousRow heights 40 and 56 (48 by default). The header row matches.
pulse-table--interactiveRows highlight on hover, for tables where a row opens something.
aria-selected="true" on a rowThe selected row: quiet fill and an edge in the selection color.
pulse-table__numRight-aligns a number column (head and cells).
pulse-table--headlessHides the header row from sight, not from screen readers.
pulse-table__revealWraps row actions that show on hover and focus.
data-optional on cells, is-condensed on the tableHides those columns, for when a drawer takes half the width.

Without a header row

pulse-table--headless keeps aligned columns with no visible head, like a mail inbox: for a list of accounts where each value says what it is (“43 assets”, “21% covered”). Keep the <thead>; screen readers still read it, and removing the class shows it again. Give the name column a fixed width with <col> so values line up across tables. Row actions go in their own last cell inside pulse-table__reveal: shown on hover and focus, always on touch screens. Their tooltips close as soon as the pointer leaves the icon (see Tooltip).

Accessibility

  • Use real <th scope="col"> heads. Clickable rows also need a link or button inside for keyboard users.
  • Numbers use tabular figures in the sans, so columns line up.
