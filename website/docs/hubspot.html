HubSpot

Creates a private app with read access to your HubSpot account’s security activity and security health.

Requires: admin access to the HubSpot account.

  1. HubSpot → Settings → Integrations → Connected Apps → Private Apps (now under Legacy Apps) → Create a private app.
  2. App name: Security monitor.
  3. Scopes tab → add account-info.security.read and settings.security.security_health.read → Create app.
  4. Auth tab → copy the Access token (starts with pat-).
  5. Fill in: 
    {
  "token": ""
}
    FieldWhere to find it
    tokenThe access token from step 4
