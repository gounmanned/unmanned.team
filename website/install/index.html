Installation instructions

Select your computer type

  1. Download the installer

    Click the “Download for Mac” button above.

    Click the “Download for Windows” button above.

    It saves a small file to your Downloads folder.

  2. Run the installer

    Open the downloaded file and follow the prompts.

    If your computer asks whether to allow it to run, choose Yes or Allow — that’s expected.

    When prompted, enter install key: Loading…

    We couldn’t load your install key. Email security@vex.unmanned.team and we’ll send it to you.

  3. Allow necessary permissions

    You may be asked to enter your computer password during installation.

    When prompted, allow Level these three permissions:

    • Screen Recording
    • Accessibility
    • Full Disk Access

    Don’t see the prompts? Open System Settings → Privacy & Security and enable the permissions above for Level.

  4. You’re covered

    All done. Our Security Operations Center can now protect your computer, 24/7. Each month, we’ll send you a simple update on how things are looking.
