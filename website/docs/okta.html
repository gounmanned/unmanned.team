Okta

Creates an Okta API token, to read your System Log.

Requires: an admin whose role includes Read System Log (Super Admin, Security Admin, or a custom role with it). The token gets its creator’s permissions; without this privilege, requests fail with 403.

  1. Okta Admin Console → Security → API → Tokens → Create Token.
  2. Name: Security log reader → Create Token.
  3. Copy the token (shown once).
  4. Fill in: 
    {
  "api_token": "",
  "base_url": ""
}
    FieldWhere to find it
    api_tokenThe token from step 3
    base_urlYour Okta org URL, no trailing slash: e.g. https://company.okta.com, https://company.oktapreview.com (preview) or your custom domain
