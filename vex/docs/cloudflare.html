Cloudflare

This guide walks you through creating a Cloudflare API token with the necessary permissions to monitor security events across all your zones.

Prerequisites

  • You have access to your Cloudflare account with domains configured.
  • Your account has Admin or Super Administrator privileges.

Step 1: Access API Token Management

  1. Log into your Cloudflare Dashboard.
  2. Navigate to the Manage Account -> Account API tokens section
  3. Under "Create token", click "Get started".
  4. Set the Token name to Vex.

Step 2: Configure Account policy

  1. Check "Read all resources" under permission polices
  2. Ensure "Entire Account" is selected (it is by default)
  3. Select No Expiration
  4. Click "Review token"
  5. Click "Create token"

Step 3: Connect Vex

  1. Add the following JSON to Vex:
{
    "account_id": "your_cloudflare_account_id",
    "api_token": "your-api-token-here"
}
  1. Save this in Vex
