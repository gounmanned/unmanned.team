Rapid7

Creates an InsightIDR custom logs webhook, so new signals arrive as raw logs.

  1. InsightIDR → Data Collection → Event Sources → Add Event Source.
  2. Add Raw Data → Custom Logs. Name: Security signals. Collection method: Webhook → Save.
  3. Copy the webhook URL (like https://xxxxx.data.logs.insight.rapid7.com/log/…).
  4. Fill in: 
    {
  "webhook": ""
}
    FieldWhere to find it
    webhookThe URL from step 3
