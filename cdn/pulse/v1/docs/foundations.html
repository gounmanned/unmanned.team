Foundations

The tokens every component and page is built from: color, type, spacing, radius and icons.

Tokens are CSS variables in pulse-tokens.css. Their names match the Figma variables. Use them in your page’s own CSS; never type a hex value or a size that a token covers.

Color

Use these role names, never a hex value. Each one has a light and a dark value; data-theme="dark" on any element switches everything inside it. The swatches below follow the theme switch at the top of this page.

Type

Each role has a -size and a -line-height. Display, the three headings and the lede are fluid: they grow smoothly from their phone size at 375px wide to their desktop size at 1280px. Fonts: --font-sans (Inter) and --font-mono (JetBrains Mono).

Radius and surface

Components never name a radius directly; they use roles like --radius-control, --radius-medium and --radius-container. data-surface="web" (the website) makes every role 2px; data-surface="app" (VEX) uses 4, 8 and 12 and pill buttons.

Icons

Phosphor icons as CSS masks, so they take the text color. Regular for normal interface, bold at 14px and below, fill for status and selected states, light only for large decorative icons. Size with --pulse-icon-size. Decorative icons get aria-hidden="true". To add one, ask the design-system side (it goes in icons.txt).
