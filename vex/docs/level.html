Level.io

This guide walks you through setting up a Level.io integration to receive real-time alerts from your devices.

Prerequisites

  • You have a Level.io account with administrative access.
  • Each device you manage is labeled with the email address of the owner

Step 1: Create an API Key

  1. Log into your Level.io dashboard.
  2. Navigate to Settings → API Keys.
  3. Click "Create API Key".
  4. Set a descriptive name like security-monitor.
  5. Copy and securely save the generated API key.

Step 2: Create a Webhook

  1. In your Level dashboard, navigate to Settings → Webhooks.
  2. Click "Create webhook".
  3. Configure your webhook settings:
    • URL: https://9vy0x0o0cc.execute-api.us-east-2.amazonaws.com/public/{my-domain.com}
    • Secret: Generate a secure secret key for signature validation
    • Event types: Select 'new alerts' and 'device updates'
    • Status: Enable the webhook
  4. Click "Create".

Step 3: Create Configuration JSON

After creating both the API key and webhook, create a JSON configuration object with your credentials:

{
  "secret": "your-webhook-secret-here",
  "token": "your-api-key-here"
}
