Microsoft Teams

This guide walks you through creating a Teams webhook so new signals go to a channel of your choice.

Prerequisites

  • You have access to your Microsoft Teams workspace with permission to add workflows to a channel.

Step 1: Open the Channel's Workflows

  1. In Microsoft Teams, go to the team and channel where you want notifications posted.
  2. Select "More options (⋯)" next to the channel name.
  3. Select "Workflows".

Step 2: Add the Webhook Workflow

  1. Search for the template "Send webhook alerts to a channel".
  2. Select it, then confirm the channel it should post to.
  3. Click "Create flow" (or "Add workflow").

Step 3: Copy the Webhook URL

  1. Once the workflow is created, copy the webhook URL it generates.
  2. It will look like:
https://xxxxx.xx.logic.azure.com:443/workflows/xxxxxxxxxxxxxxxxxxxx/triggers/manual/paths/invoke?...
Treat this URL as a secret. Anyone who has it can post messages to your channel. Don't commit it to source control or share it outside your team.

Step 4: Save to Vex

  1. In the configuration input box, create a JSON object with this structure:
{
    "webhook": "https://xxxxx.xx.logic.azure.com:443/workflows/your-webhook-path-here"
}
