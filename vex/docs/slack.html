Slack

This guide walks you through connecting Slack so VEX can send events to a channel of your choice. VEX supports two ways to connect: an incoming webhook or a bot. Pick whichever fits your setup — you only need one.

Notification integration: Slack is a notification integration, not a security monitor. It doesn't scan or find issues on its own — it delivers events (alerts, status changes, connection updates, etc.) from your other security monitors into Slack in real time. Set up a security monitor separately to generate the events this integration will notify you about.

Which should I use?

  • Webhook — fastest to set up, posts to a single fixed channel chosen when you create the webhook. Good if you only need notifications in one place.
  • Bot — slightly more setup, but the channel is configurable and can be changed later without recreating the connection. Also required if you want threaded replies (e.g. a follow-up "resolved" notification posted under the original alert).

Option A: Webhook

Step 1: Create a Slack App

  1. Go to api.slack.com/apps and log into your workspace.
  2. Click "Create New App".
  3. Choose "From scratch".
  4. Set the App Name to VEX Notifications and select your workspace.
  5. Click "Create App".

Step 2: Enable Incoming Webhooks

  1. From your app's settings page, select "Incoming Webhooks" under Features.
  2. Toggle "Activate Incoming Webhooks" to on.
  3. Click "Add New Webhook to Workspace" at the bottom of the page.

Step 3: Choose a Channel

  1. Select the channel you want VEX to post notifications to.
  2. Click "Allow".

Step 4: Copy the Webhook URL

  1. Back on the "Incoming Webhooks" page, find the webhook listed under "Webhook URLs for Your Workspace".
  2. Click "Copy" to copy the URL. It will look like:
Treat this URL as a secret. Anyone who has it can post messages to your channel. Don't commit it to source control or share it outside your team.

Step 5: Upload Webhook to VEX

  1. Create a new text file and name it slack.json.
  2. Using the URL from Step 4, create a JSON object with this structure:
{
    "webhook": "https://hooks.slack.com/services/your-webhook-path-here"
}
  1. Save this in VEX

Option B: Bot

Already created a Slack app for the webhook above? You can reuse it — there's no need for a second app. Skip to Step 2 and add the bot scope to your existing "VEX Notifications" app instead.

Step 1: Create a Slack App

  1. Go to api.slack.com/apps and log into your workspace.
  2. Click "Create New App".
  3. Choose "From scratch".
  4. Set the App Name to VEX Notifications and select your workspace.
  5. Click "Create App".

Step 2: Add the Bot Token Scope

  1. From your app's settings page, select "OAuth & Permissions" under Features.
  2. Scroll to "Scopes" and, under "Bot Token Scopes", click "Add an OAuth Scope".
  3. Add chat:write.

Step 3: Install the App

  1. Scroll back to the top of the "OAuth & Permissions" page.
  2. Click "Install to Workspace", review the permissions, and click "Allow".

Step 4: Copy the Bot Token

  1. After installing, you'll land back on "OAuth & Permissions".
  2. Copy the "Bot User OAuth Token" at the top of the page. It starts with xoxb-.
Treat this token as a secret. Anyone who has it can post messages as your bot. Don't commit it to source control or share it outside your team.

Step 5: Choose a Channel

  1. Decide which channel you want VEX to post notifications to, and note its name (e.g. #security-alerts).
  2. In Slack, open that channel and invite the bot with: 
    /invite @VEX Notifications
The bot must be a member of the channel. If it isn't invited, VEX won't be able to post there and connection testing will fail with not_in_channel.

Step 6: Upload Bot Credentials to VEX

  1. Create a new text file and name it slack.json.
  2. Using the token from Step 4 and the channel from Step 5, create a JSON object with this structure:
{
    "token": "xoxb-your-bot-token-here",
    "channel": "#security-alerts"
}
  1. Save this in VEX
