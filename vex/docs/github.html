GitHub

This guide walks you through creating a fine-grained personal access token scoped to your GitHub organization, and storing it so Vex can periodically scan your repositories for security flaws.

Prerequisites

  • You have access to a GitHub organization whose repositories you want scanned.
  • If you are not an organization owner, an org owner may need to approve the token before it becomes active (see Step 3).

Step 1: Access Developer Settings

  1. Log into GitHub and click your profile photo in the top right.
  2. Click Settings, then scroll to the bottom of the left sidebar and click Developer settings.
  3. Click Personal access tokens → Fine-grained tokens, then click "Generate new token".

Step 2: Configure the Token

  1. Set the Token name to Vex Security Scanner.
  2. Set an Expiration. Fine-grained tokens cannot be non-expiring — choose the maximum (1 year) and plan to rotate it before it lapses.
  3. Under Resource owner, select your organization instead of your personal account. If your organization does not appear, it may not have fine-grained PAT access enabled.
  4. Under Repository access, select "All repositories" so newly created repos are covered automatically, or "Only select repositories" to scope it manually.
  5. Under Permissions, grant only what Vex needs:
Contents: Read-only
Metadata: Read-only
Security events: Read and write

Grant Security events: Read and write only if Vex will publish findings back as GitHub code scanning alerts. Otherwise, Read-only permissions are sufficient.

  1. Click "Generate token".

Step 3: Organization Approval

  1. Many organizations require owner approval before a fine-grained token can access their repositories.
  2. If approval is required, the token remains in a pending state until an org owner approves it under Organization Settings → Personal access tokens → Pending requests.
  3. The token will not work until it has been approved.

Step 4: Copy Your Token

  1. Copy the generated token immediately — GitHub will not show it again after you navigate away.
  2. Store it securely before proceeding.

Step 5: Save to Vex

Inside Vex, add your credential in the following JSON format:

{"token": "$GITHUB_TOKEN"}

Once registered, Vex will run periodic security scans across your organization's repositories using this token.
