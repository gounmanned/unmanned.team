HubSpot

This guide walks you through creating a private app with API access for your HubSpot account. The resulting credentials will allow us to monitor security events and detect suspicious activity in your HubSpot portal.

Prerequisites

  • You have admin access to your HubSpot account
  • You can access the HubSpot Settings menu

Step 1: Create Private App

  1. Log into your HubSpot account.
  2. Navigate to Settings → Integrations → Connected Apps.
  3. Look for the Private Apps section or Legacy Apps tab (HubSpot has moved private apps to the legacy section).
  4. Click Create a private app.
  5. Fill in the app details:
  • App name: Vex
  • Description: Security monitoring

Step 2: Configure Scopes

  1. Navigate to the Scopes tab in your private app.
  2. Add the following two scopes:
account-info.security.read
settings.security.security_health.read
  1. Click Create app.

Step 3: Get Access Token

  1. Once the app is created, navigate to the Auth tab.
  2. Copy the Access token.
  3. Verify the token starts with pat- (this confirms it's a private app token).
  4. The token will look like:
pat-na1-12345678-abcd-1234-efgh-123456789abc

Step 4: Save to Vex

Inside Vex, add the HubSpot credentials in the following JSON format:

{
  "token": "pat-na1-12345678-abcd-1234-efgh-123456789abc"
}

Replace the token with your actual access token from Step 3.

What Is Monitored

With these credentials, we will monitor your HubSpot account for:

  • Data export activities (who downloaded customer data)
  • User management changes (admin additions, removals, invitations)
  • Integration installations and changes
  • API access token activities
  • Permission and role modifications
