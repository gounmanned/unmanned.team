FAQ

Questions we hear most

What's the difference between this and a SIEM?+
A SIEM waits for logs and tells you something happened. Vex starts before that — mapping the choke points an attacker would use and helping you close them — then layers detection and response on top for anything that still gets through.
Do we need to replace our RMM or EDR?+
No. Vex connects to the agent you already run and starts pulling telemetry — no parallel agent, no migration project before coverage begins.
Who actually responds when something fires?+
Vex takes the first action automatically — isolating an endpoint or revoking a session — and our SOC verifies and owns the case from there, in the same board you already have access to.
How is this priced?+
Per seat, custom-quoted to your environment — not by log volume or data ingested, so cost doesn't move against you as coverage expands.
Can we keep our own detection rules?+
Yes. Run on the defaults we maintain, or define your own indicators of compromise and response rules on top of them.
