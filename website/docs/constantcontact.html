Constant Contact

Registers an OAuth app with access to your Constant Contact account, contacts and campaigns.

Requires: admin access to the Constant Contact account, and a Constant Contact developer account.

  1. V3 API Developer Portal → My Applications → New Application.
  2. App name: Security monitor. OAuth2 flow: Authorization Code Flow. Refresh token type: Long Lived → Create.
  3. Edit next to the app → copy the API Key.
  4. Generate Client Secret → copy it (shown once). Keep the Redirect URI https://localhost → Save.
  5. Open this URL in a browser, with your API key in place of {client_id} and any random text in place of {state}. Sign in and allow access. 
    https://authz.constantcontact.com/oauth2/default/v1/authorize?client_id={client_id}&redirect_uri=https://localhost&response_type=code&scope=account_read contact_data campaign_data offline_access&state={state}
  6. The browser goes to https://localhost/?code=… (the page won’t load). Copy the code value. It expires in 5 minutes and works once.
  7. Run in Terminal, with your values in place of the braces: 
    curl -X POST https://authz.constantcontact.com/oauth2/default/v1/token \
  -u "{client_id}:{client_secret}" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=authorization_code" \
  -d "code={code}" \
  -d "redirect_uri=https://localhost"
  8. Fill in: 
    {
  "client_id": "",
  "client_secret": "",
  "refresh_token": ""
}
    FieldWhere to find it
    client_idThe API Key from step 3
    client_secretThe client secret from step 4
    refresh_tokenrefresh_token in the response from step 7
