Jira

This guide walks you through creating an Atlassian API token scoped to your Jira site, and storing it so Vex can periodically create tickets in your projects.

Prerequisites

  • You have access to a Jira Queue whose projects you want Vex to create tickets in.
  • If your organization restricts API token creation, an org admin may need to allow it (see Step 3).

Step 1: Access API Token Settings

  1. Log into Atlassian with the account tied to your Jira site.
  2. Click "Create API token with scopes". Atlassian is phasing out unscoped "classic" tokens in favor of scoped ones, so use a scoped token for any new integration.

Step 2: Configure the Token

  1. Set the Token name to Vex Ticket Creator.
  2. Set an Expiration. Scoped tokens cannot be non-expiring — expiration is capped at 365 days, so choose the maximum and plan to rotate it before it lapses.
  3. Under App, select Jira.
  4. Under Scopes, grant only what Vex needs:
Jira work items: Read
Jira work items: Write

Grant Write access — Vex needs it to create tickets. Read-only scopes will let Vex see your projects but not create anything in them.

  1. Click "Generate".

Step 3: Organization Restrictions

  1. Some Atlassian organizations restrict API token creation or usage through an org-level API token policy.
  2. If token creation is blocked, ask an org admin to allow it under Organization Settings → Security → API token policy.
  3. The token will not work until your organization permits API token access.

Step 4: Copy Your Token

  1. Copy the generated token immediately — Atlassian will not show it again after you navigate away.
  2. Store it securely before proceeding.

Step 5: Save to Vex

Inside Vex, add your credential in the following JSON format, including your Jira site's base URL and the key of the project you want tickets created in:

{
  "email": "you@example.com",
  "api_token": "$JIRA_TOKEN",
  "base_url": "https://examplecompany.atlassian.net",
  "project_key": "QUEUENAME"
}

project_key is the short, uppercase identifier for the Jira project you want tickets created in (for example, OPS or SUP). You can find it in the URL of any issue in that project, or under Project settings → Details.

Once registered, Vex will create tickets in the specified Jira project using this token.
