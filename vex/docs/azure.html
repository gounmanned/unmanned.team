Azure

This guide walks you through grantingaccess to your Azure subscriptions so it can inventory your cloud resources.

Step 1: Locate the VEX App Registration

  1. Go to Azure Portal → App registrations.
  2. Select the VEX app registration created during Microsoft 365 setup.
  3. If it doesn't exist yet, click "New registration", name it VEX, select "Single tenant only", leave "Redirect URI" blank, and click "Register". Then create a client secret under "Certificates & secrets" as described in the Microsoft 365 guide.

Step 2: Assign the Reader Role

  1. Navigate to management group in the Azure Portal.
  2. Select "Access control (IAM)" in the left menu.
  3. Click "Add" → "Add role assignment".
  4. Under "Role", search for and select "Reader". This is a built-in Azure role that grants read-only visibility into every resource type in-scope — VMs, storage accounts, function apps, networking, and more.
  5. Click "Next". Under "Assign access to", choose "User, group, or service principal".
  6. Click "+ Select members", search for VEX, select the app registration, and click "Select".
  7. Click "Review + assign" twice to confirm.

Step 3: Save

  1. Using the values from the app registration, create a JSON object with this structure:
{
    "tenant_id": "your-directory-tenant-id-here",
    "client_id": "your-application-client-id-here", 
    "client_secret": "your-client-secret-value-here"
}
  1. Replace the placeholder values with your actual credentials:
  2. tenant_id: The Directory (tenant) ID from the app registration's Overview page
  3. client_id: The Application (client) ID from the app registration's Overview page
  4. client_secret: The secret value created under "Certificates & secrets"
  5. Paste this JSON in the credentials input for the Azure integration inside VEX.
  6. Click Connect.
