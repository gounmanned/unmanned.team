Google Workspace

This guide walks you through creating a service account in Google Cloud Platform (GCP) with domain-wide delegation. The resulting JSON credentials file will allow API access to:

  • Google Workspace Alert Center
  • Google Admin Directory Users

Prerequisites

  • You have a Super Admin account with an email address of admin@your-domain.com
  • You have a Google Cloud Project
  • Admin SDK API is enabled

Step 1: Create a Service Account

  1. Go to Google Cloud Console.
  2. Choose or create a project.
  3. Click "Create Service Account".
  4. Set a name like security-monitor and click "Create and Continue".
  5. Click Done.

Step 2: Disable organization policy

  1. From inside your console, go "back" one directory to your organization
  2. Go to Organization Policies
  3. Search for a policy called ``iam.disableServiceAccountKeyCreation``
  4. Click Manage Policy
  5. Change from enforced to not enforced
  6. Save

Step 3: Create a JSON Credentials File

  1. In the Service Accounts list, click your service account.
  2. Go to the "Keys" tab.
  3. Click "Add Key" → "Create new key".
  4. Select JSON, then click Create.
  5. Download and save the generated .json file securely.

Step 4: Enable Domain-Wide Delegation

  1. Still in the service account, click "Show Domain-wide Delegation".
  2. Copy the Client ID shown.

Step 5: Grant Scopes in Admin Console

  1. Visit Admin Console → Security → API Controls.
  2. Click "Manage Domain-Wide Delegation".
  3. Click "Add new".
  4. Paste the Client ID.
  5. Add the following scopes:
    https://www.googleapis.com/auth/apps.alerts
    https://www.googleapis.com/auth/drive.readonly
    https://www.googleapis.com/auth/admin.directory.user.readonly
    https://www.googleapis.com/auth/admin.directory.device.chromeos.readonly
  1. Save
  2. Go back to Sam and paste the JSON contents into the monitor and Save.
