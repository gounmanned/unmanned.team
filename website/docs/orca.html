Orca

Creates an Orca Security API token, to read alerts, assets and cloud accounts.

Requires: a role that can create API tokens (Admin, Security Admin, or a custom role with api_tokens:create). If you don’t have one, an organization admin adds it or creates the token.

  1. Orca Security console → Settings → API Tokens → Create New Token.
  2. Token name: Security monitor. Expiration: up to 365 days. Replace the token before it expires.
  3. Permissions:
    PermissionAccess
    AlertsRead
    AssetsRead
    Cloud AccountsRead
    ScansTrigger, only to allow on-demand scans
  4. Generate → copy the token (shown once).
  5. Fill in: 
    {
  "api_token": "",
  "base_url": ""
}
    FieldWhere to find it
    api_tokenThe token from step 4
    base_urlhttps://api.orcasecurity.io for most accounts. Dedicated or EU region: ask your Orca contact (e.g. https://api.eu.orcasecurity.io)
