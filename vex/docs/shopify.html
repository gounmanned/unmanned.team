Shopify

This guide walks you through creating a custom app with an API access token for your Shopify store. The resulting credentials will allow us to monitor events and detect security-relevant activity in your store.

Prerequisites

  • You have admin access to your Shopify store
  • You know your store's name (e.g., your-store-name.myshopify.com)

Step 1: Enable Custom App Development

  1. Log into your Shopify admin panel.
  2. Go to Settings (bottom left).
  3. Click Apps and sales channels.
  4. Click Develop apps.
  5. If prompted, click Allow custom app development and confirm.

Step 2: Create a Custom App

  1. Click Create an app.
  2. Enter an app name like Security Monitor.
  3. Select yourself as the app developer.
  4. Click Create app.

Step 3: Configure API Scopes

  1. Click on the Configuration tab.
  2. Under Admin API integration, click Configure.
  3. In the Admin API access scopes section, select the following scopes:
read_products
read_orders
read_customers
read_content
  1. Click Save.

Step 4: Install the App

  1. Click on the API credentials tab.
  2. Click Install app.
  3. Click Install to confirm.

Step 5: Reveal and Copy Your Access Token

  1. Under Admin API access token, click Reveal token once.
  2. Copy the access token that appears.
  3. The token will look like:
shpat_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Step 6: Prepare Your Credentials

You'll need to provide both your store name and access token in JSON format:

{
  "shop_name": "your-store-name",
  "access_token": "shpat_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
}

Replace your-store-name with your store name (without .myshopify.com).

What Is Monitored

With these credentials, we will monitor your Shopify store for:

  • Mass deletion events (products, collections, customers)
  • Suspicious app activity
  • Customer data modifications
  • Unusual order patterns
  • Critical resource changes
