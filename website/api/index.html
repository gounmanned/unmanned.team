The setup

Set it.
Forget it.

Connecting a monitor takes about as long as reading this sentence. Slightly less, if you skim.

1
Pick one
Whatever's actually running your business. Check the list above. We meant it about the "many more."
2
Hand over the keys
One authenticated call. POST /monitor/{name}. It wants credentials, not your firstborn.
3
Walk away
GET /monitor confirms it worked. Then, genuinely, stop thinking about it. That's the entire pitch.

We do the hard work. You'll hear from us only when your attention is actually required, which is rarer than you'd think, and we're a little smug about that.

For the ones who read the manual

Fine. Here's the actual request. No metaphors this time.

connect-monitor.js JavaScript 
// Google Workspace: service account JSON key
await fetch(`${BASE}/monitor/google`, {
  method: 'POST',
  headers, // Authorization: Bearer <id_token>
  body: JSON.stringify({
    type: 'service_account',
    project_id: 'your-project-id',
    private_key_id: '...',
    private_key: '-----BEGIN RSA PRIVATE KEY-----\n...',
    client_email: 'vex@your-project.iam.gserviceaccount.com',
  }),
}).then(r => r.json());

// Microsoft 365: app registration credentials
await fetch(`${BASE}/monitor/microsoft`, {
  method: 'POST',
  headers,
  body: JSON.stringify({
    tenant_id:     'your-tenant-id',
    client_id:     'your-app-client-id',
    client_secret: 'your-app-secret',
  }),
}).then(r => r.json());

// That's it. No polling loop to write, no cron job to babysit.
confirm-connected.js JavaScript 
// Step 3, for real: proof of life
const monitors = await fetch(`${BASE}/monitor`, { headers })
  .then(r => r.json());

console.log(monitors); // ['google', 'microsoft']; now go do something else
The signal

While you sleep,
Vex is still looking for a way in.

Everything your monitors see becomes a signal: a login from somewhere new, a setting quietly switched off, a device that stopped checking in. On their own, these are almost always nothing. "Almost always" is doing a lot of work in that sentence. Vex checks anyway, the same way an attacker would, trying to chain them together into an actual way in. Continuously. Automatically. It does not take weekends.
