Orca Security

This guide walks you through creating an Orca Security API token, and storing it so VEX can periodically interact with your Orca environment to fetch alerts, manage assets, or trigger scans.

Prerequisites

  • You have access to an Orca Security account with permissions to manage API tokens.
  • You hold a role that allows API token creation (typically Admin, Security Admin, or a custom role with api_tokens:create permission).

Step 1: Access API Token Settings

  1. Log into the Orca Security Console with your administrator or authorized account.
  2. In the left navigation, go to Settings → API Tokens.
  3. Click "Create New Token".

Step 2: Configure the Token

  1. Set the Token Name to VEX Integration (or a descriptive name identifying the integration).
  2. Set an Expiration. Orca tokens can be set to expire at a specific date (recommended: 365 days maximum). Plan to rotate the token before it lapses.
  3. Under Permissions / Scopes, grant only what VEX needs. Recommended minimal scopes:
Alerts: Read
Assets: Read
Cloud Accounts: Read
Scans: Trigger (optional, if VEX should initiate on-demand scans)

Grant Read access for Alerts and Assets — VEX needs this to fetch findings and inventory. Only grant Scans: Trigger if you want VEX to start new scans programmatically.

  1. Click "Generate".

Step 3: Organization / Role Restrictions

  1. Some Orca organizations enforce role-based access control (RBAC) that may restrict API token creation to specific roles.
  2. If token creation is blocked, ask an Organization Admin to ensure your role includes the api_tokens:create permission, or have them create the token on your behalf.

Step 4: Copy Your Token

  1. Copy the generated token immediately — Orca will not show it again after you close the dialog or navigate away.
  2. Store it securely (e.g., in a password manager or your secrets vault) before proceeding.

Step 5: Save in VEX

Inside VEX, add your credential in the following JSON format, including your Orca environment's base URL and the token you just created:

{
  "api_token": "$ORCA_API_TOKEN",
  "base_url": "https://api.orcasecurity.io"
}

base_url is the Orca API endpoint for your region. Most customers use https://api.orcasecurity.io. If you are on a dedicated or EU region, confirm the correct endpoint with your Orca CSM (e.g., https://api.eu.orcasecurity.io).

Once registered, VEX will use this token to authenticate API requests to your Orca environment.
