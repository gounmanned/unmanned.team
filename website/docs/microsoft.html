Microsoft 365

Creates an app registration with Microsoft Graph application permissions, to monitor and respond to security events across Microsoft 365.

Requires: an admin who can grant admin consent (Global Administrator or Privileged Role Administrator).

  1. Azure Portal → App registrations → New registration.
  2. Name: Security monitor. Supported account types: Single tenant only. Leave Redirect URI blank → Register.
  3. Certificates & secrets → Client secrets → New client secret → Description: Security monitor, Expires: 24 months → Add. Copy the Value (shown once).
  4. API permissions → Add a permission → Microsoft Graph → Application permissions.
  5. Add each of these → Add permissions: 
    User.Read.All
Group.Read.All
Device.Read.All
ServiceMessage.Read.All
AuditLog.Read.All
Organization.Read.All
SecurityAlert.ReadWrite.All
Sites.Read.All
Files.Read.All
Policy.Read.All
User.EnableDisableAccount.All
User.RevokeSessions.All
MailboxSettings.Read
  6. Grant admin consent for your organization → Yes.
  7. Fill in: 
    {
  "tenant_id": "",
  "client_id": "",
  "client_secret": ""
}
    FieldWhere to find it
    tenant_idOverview → Directory (tenant) ID
    client_idOverview → Application (client) ID
    client_secretThe secret’s Value from step 3
